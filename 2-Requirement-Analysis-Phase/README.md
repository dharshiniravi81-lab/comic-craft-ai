# 2. Requirement Analysis Phase
**Project:** ComicCraft - AI Comic Story Creator using Gemini Models

## Technical Architecture & Pre-requisites
* **Backend Framework:** FastAPI & Uvicorn ASGI Server
* **Programming Language:** Python 
* **Frontend:** HTML, CSS, and Jinja2 Templates
* **AI Models:** 
  - Google Gemini API (Gemini 1.5 Flash & Pro)
  - Hugging Face Diffusers (Stable Diffusion v1-5)
* **Libraries:** PyTorch, FPDF (for PDF Generation), Pillow, Transformers
* **Environment Setup:** Python Package & Environment Setup (pip, virtualenv)
