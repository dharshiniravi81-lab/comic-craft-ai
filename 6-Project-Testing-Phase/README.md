# 6. Project Testing Phase
**Project:** ComicCraft - AI Comic Story Creator using Gemini Models

## Testing Details
* **Local Server Testing:** We ran the backend server locally using Uvicorn and checked if the frontend loaded correctly on `127.0.0.1:8000`.
* **API Testing:** We tested the `/test-image` route to make sure the Hugging Face model was generating images properly before mixing it with the story.
* **PDF Export Testing:** We generated a sample comic and clicked the download button to ensure the code correctly combined the images and text into a final PDF file. Everything worked smoothly!
